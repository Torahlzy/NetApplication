## 如何新增

1. 在 `wiki/经验/`（或其它分类目录）新建 `.md` 文件，标题与正文用中文；
2. 遵循既有写法：**现象 → 排查过程/证据(关键日志、复现实验) → 根因 → 修复 → 启发/回归清单**；
3. 回到本页索引表格加一行，方便检索。

- 涉及具体页面的功能改动，入口与代码约定见根目录 `AGENTS.MD`；
